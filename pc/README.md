# Messenger 2026 — ПК (тестовая сборка)

Нужны Node.js 18+ и Windows.

1. Распакуйте папку и откройте её в терминале.
2. `npm install`
3. Запуск без сборки: `npm start`
4. Готовый файл `.exe`: `npm run dist`. Он появится в папке `dist/`.

Это визуальная тестовая сборка: страница `www/index.html` — десктопная версия v20.
Активность Spotify/Яндекс/YouTube через помощник на 127.0.0.1 в этой оболочке может не работать.
